Command Palette 截图

按 Ctrl+P 打开命令面板 (VSCode 风格)。↑↓ 选命令，Enter 执行，Esc 关闭。搜索对 title / keybinding / group 做不区分大小写子串匹配。

A. 空查询 (全部命令, 按 group 分组)

empty query展示所有命令 + group headers
11 个命令 + 4 个 group header (Mode / Window / Chat / App)

B. 搜索 "intensity" (过滤后)

query = "intensity"只剩 intensity_cycle 命令
group header 保留, 只显示匹配的 command (第一个非 disabled 自动 highlight)

C. 搜索 "quit" (按 keybinding 匹配)

query = "quit"按 keybinding "q / Ctrl+C" 匹配也能命中
title / keybinding / group / name 四个字段都参与子串匹配

D. 无匹配

query = "xyz_nomatch"没匹配时显示 [No matches]
空状态优雅处理, Enter 不会崩
