## 1. 模块概述

### 1.1 核心职责

配置管理模块（`server/src/core/config/`）统一管理 MyOpenClaw 所有运行期配置，提供：

| 职责 | 实现 |
|------|------|
| **多源合并** | defaults < yaml < json < env 优先级链 |
| **类型校验** | Zod schema 强制字段类型、范围、必填 |
| **跨字段规则** | validator.ts 检查 ws.port≠http.port、authToken 强度等 |
| **环境变量覆盖** | `MYOC_*` 前缀 + camelCase / 全小写两种命名风格 |
| **路径解析** | `~` 展开、XDG 风格用户目录、env 覆盖 |
| **错误分级** | fatal (exit 1) / warning (继续) / info (纯提示) |

### 1.2 在六层架构中的定位

```
┌─────────────────────────────────────┐
│  Channels (渠道) — 入口消息         │
├─────────────────────────────────────┤
│  Gateway (网关) — 路由/调度/认证     │
├─────────────────────────────────────┤
│  Agent Runtime (核心)               │
│    ├ Planner    ← getConfig('llm.*')│
│    ├ Tools      ← getConfig('sec.*')│
│    └ Orchestrator                    │
├─────────────────────────────────────┤
│  Tools / Memory / Skills            │
│    └ loadAgentConfig('default')     │
├─────────────────────────────────────┤
│  Core — Config (配置管理)           │
│    └ loadConfig() ← src/index.ts    │
└─────────────────────────────────────┘
```

**所有其他模块都通过 `loadConfig()` / `getConfig()` / `loadAgentConfig()` 读配置**，没有第二路径。

### 1.3 目录结构

```
server/src/core/config/
├── schema.ts          # Zod 10 段顶层 schema (app/network/llm/...)
├── types.ts           # Zod 推导类型导出
├── defaults.ts        # getDefaultConfig() — 兜底默认
├── paths.ts           # ~ 展开 + JSON 路径解析
├── errors.ts          # ConfigFatalError + zodToIssues()
├── json-loader.ts     # ~/.myopenclaw/config.json 加载 + 校验
├── yaml-loader.ts     # config/config.yaml + includes + ${VAR}
├── merger.ts          # deepMerge + applyEnvOverrides
├── validator.ts       # 跨字段业务规则 + 致命错误
├── loader.ts          # loadConfig / getConfig / loadAgentConfig 组合入口
└── index.ts           # 聚合导出
```

## 2. 配置加载优先级链

### 2.1 优先级总览

**低 ──────────────────────────────────── 高**

1. **defaults** (`defaults.ts`) — schema .default() 触发的兜底值
2. **项目 YAML** (`config/config.yaml` + includes) — 团队共享配置
3. **用户 JSON** (`~/.myopenclaw/config.json` 或 `MYOC_CONFIG_PATH`) — 个人覆盖
4. **环境变量** (`MYOC_*` 前缀) — 容器化部署 / 临时覆盖
5. **启动期校验** (`validator.ts`) — 不在合并链里，最后一步校验

**后加载的源**整体覆盖**前一源的同名字段**（deepMerge 递归，数组整体替换）。

### 2.2 默认配置 (defaults)

```typescript
// server/src/core/config/defaults.ts
export function getDefaultConfig(): MyOpenClawConfig {
  return MyOpenClawConfigSchema.parse({
    network: { ws: {...}, http: {...} },
    llm: { provider: 'deepseek', apiKey: '__PLACEHOLDER__', ... },
    embedding: { provider: 'openai', apiKey: '__PLACEHOLDER__', ... },
    memory: { persist: { backend: 'sqlite', path: '~/.myopenclaw/data/memory.db' } },
    security: { authToken: 'dev-only-default-token-please-change', ... },
  });
}
```

**注意**：apiKey/authToken 用 `__PLACEHOLDER__` 字符串占位，让 schema refine 通过；validator 检测到 PLACEHOLDER 字样 → **fatal 启动**，提示用户必须显式覆盖。

### 2.3 项目 YAML (config/config.yaml)

- 路径：`process.cwd() + '/config/config.yaml'`，可被 `MYOC_PROJECT_CONFIG_DIR` env 覆盖
- 支持 `include: [agents/default.yaml, ...]` 指令（子配置先加载，主配置后覆盖）
- 支持 `${VAR_NAME}` 引用（env 未设时**保留字面**，不替换为空串）

**示例**：
```yaml
include:
  - agents/default.yaml
network:
  ws: { host: 127.0.0.1, port: 18780 }
llm:
  provider: deepseek
  apiKey: ${DEEPSEEK_API_KEY}
```

### 2.4 用户 JSON (~/.myopenclaw/config.json)

**路径解析优先级**：
1. `process.env.MYOC_CONFIG_PATH`（完整路径）
2. `process.env.MYOC_CONFIG_DIR` + `/config.json`
3. 默认 `~/.myopenclaw/config.json`

**示例**（参考 `config/config.example.json`）：
```json
{
  "llm": {
    "provider": "deepseek",
    "apiKey": "sk-real-key-32-chars-1234567890"
  }
}
```

**错误行为**：
- 文件不存在 → 降级到项目 YAML（info 提示，不报错）
- 文件存在但 JSON 解析失败 → `ConfigFatalError`，启动期终止
- 文件存在但 schema 校验失败 → `ConfigFatalError`，列出每个字段错误

### 2.5 环境变量 (MYOC_*)

- 遍历 `process.env`，仅 `MYOC_` 前缀生效
- 显式映射（camelCase 保留）+ 自动转换（全小写 + 点分隔）
- 详见 [§4 环境变量映射规则](#4-环境变量映射规则)

### 2.6 启动期校验

合并完成后调用 `validateStartupConfig(merged)`：
- schema-level 校验在合并**前**对 JSON 做（json-loader 内部）
- 跨字段校验在合并**后**对 merged 对象做（validator.ts）

**致命问题抛 `ConfigFatalError`**，loader 内部打印到 stderr，src/index.ts 捕获后 `exit(1)`。

## 3. JSON Schema 字段说明

完整 schema 见 `server/src/core/config/schema.ts`。本节列出**生产环境需要关注的字段**。

### 3.1 app — 应用元信息

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `name` | string | `myopenclaw` | 应用名 |
| `version` | string | (从 package.json) | 版本号 |
| `mode` | enum | `production` | `production` / `development` / `test` |

**注意**：`mode=production` 时 `security.authToken` 必须 ≥ 32 字符（validator 强校验）。

### 3.2 network — 网络通信

| 段 | 字段 | 类型 | 默认 | 范围 |
|----|------|------|------|------|
| `ws` | `host` | string | `127.0.0.1` | 非空 |
| | `port` | int | `18780` | 1-65535 |
| | `path` | string | `/ws` | 1-256 |
| `http` | `host` | string | `127.0.0.1` | 非空 |
| | `port` | int | `18790` | 1-65535 |
| | `basePath` | string | `''` | max 256 |
| `timeout` | `connectMs` | int | `10000` | 100-120000 |
| | `readMs` | int | `30000` | 100-300000 |
| `pool` | `maxConnections` | int | `100` | 1-10000 |
| `cors` | `origins` | string[] | `['http://localhost:3000']` | 至少 1 个 |
| `tls` | `enabled` | bool | `false` | |
| | `certPath` | string | `~/certs/server.crt` | enabled=true 时文件必须存在 |

**跨字段约束**：`ws.port ≠ http.port`（validator 强校验）。

### 3.3 llm — LLM 服务

| 字段 | 类型 | 默认 | 必填 | 说明 |
|------|------|------|------|------|
| `provider` | enum | — | ✅ | `openai` / `anthropic` / `deepseek` / `ollama` / `custom` |
| `apiKey` | string | `__PLACEHOLDER__` | ✅(非 ollama) | **生产必须显式覆盖** |
| `baseUrl` | URL | — | ✅ | http(s) URL |
| `defaultModel` | string | — | ✅ | 必须在 `models[].id` 列表中 |
| `models` | ModelDef[] | — | ✅(≥1) | 模型定义列表 |
| `modelParams.temperature` | float | `0.7` | | 0-2 |
| `modelParams.reasoningEffort` | enum | `high` | | `none` / `low` / `medium` / `high` |
| `rateLimit.requestsPerMinute` | int | `60` | | 1-10000 |
| `retry.maxRetries` | int | `2` | | 0-10 |
| `proxy.enabled` | bool | `false` | | 启用时 `url` 必填 |

**关键约束**（validator）：
- `provider ≠ ollama` 时 `apiKey` 必须**非空字符串**（schema refine）
- `defaultModel` 必须在 `models[].id` 中
- `proxy.enabled=true` 时 `url` 必填
- `apiKey` 包含 `PLACEHOLDER` 字样 → fatal

### 3.4 embedding — 嵌入模型

| 字段 | 类型 | 默认 | 必填 | 说明 |
|------|------|------|------|------|
| `provider` | enum | — | ✅ | `openai` / `cohere` / `local` |
| `apiKey` | string | `__PLACEHOLDER__` | ✅(非 local) | **生产必须显式覆盖** |
| `baseUrl` | string | — | ✅ | 非空 |
| `model` | string | — | ✅ | 嵌入模型 ID |
| `dimensions` | int | — | ✅ | 1-10000 |
| `batchSize` | int | `64` | | 1-2048 |

**关键约束**：`provider ≠ local` 时 `apiKey` 必填（包含 PLACEHOLDER → fatal）。

### 3.5 memory — 记忆层

| 段 | 字段 | 类型 | 默认 | 说明 |
|----|------|------|------|------|
| `session` | `maxMessages` | int | `50` | 1-10000 |
| | `ttlSeconds` | int | `86400` | 60-365 天 |
| `vector` | `backend` | enum | `local` | `local` / `qdrant` / `chroma` |
| | `dimension` | int | `1536` | 1-10000 |
| | `distance` | enum | `cosine` | `cosine` / `dot` / `euclidean` |
| `persist` | `backend` | enum | `sqlite` | `sqlite` / `postgres` / `none` |
| | `path` | string | `~/.myopenclaw/data/memory.db` | `backend≠none` 时必填 |

### 3.6 security — 安全

| 字段 | 类型 | 默认 | 必填 | 说明 |
|------|------|------|------|------|

### 3.7 paths — 路径

| 字段 | 类型 | 默认 | 说明 |

## 4. 环境变量映射规则

### 4.1 显式映射表 (camelCase 保留)

`server/src/core/config/merger.ts:applyEnvOverrides()` 维护一张**显式映射表**，保留 JSON 字段的 camelCase 风格：

| 环境变量 | 目标路径 |
|----------|----------|
| `MYOC_LLM_API_KEY` | `llm.apiKey` |
| `MYOC_LLM_APIKEY` | `llm.apiKey` (兼容无下划线) |
| `MYOC_LLM_PROVIDER` | `llm.provider` |
| `MYOC_LLM_BASE_URL` | `llm.baseUrl` |
| `MYOC_LLM_BASEURL` | `llm.baseUrl` |
| `MYOC_LLM_DEFAULT_MODEL` | `llm.defaultModel` |
| `MYOC_EMBEDDING_API_KEY` | `embedding.apiKey` |
| `MYOC_EMBEDDING_PROVIDER` | `embedding.provider` |
| `MYOC_EMBEDDING_BASE_URL` | `embedding.baseUrl` |
| `MYOC_EMBEDDING_MODEL` | `embedding.model` |
| `MYOC_EMBEDDING_DIMENSIONS` | `embedding.dimensions` |
| `MYOC_SECURITY_AUTHTOKEN` | `security.authToken` |
| `MYOC_PATHS_DATA` | `paths.data` |
| `MYOC_PATHS_LOGS` | `paths.logs` |
| `MYOC_PATHS_WORKSPACE` | `paths.workspace` |
| `MYOC_LOGGING_LEVEL` | `logging.level` |
| `MYOC_LOGGING_FORMAT` | `logging.format` |
| `MYOC_LOGGING_OUTPUT` | `logging.output` |
| `MYOC_LOGGING_FILE` | `logging.file` |

### 4.2 自动转换 (全小写 + 点分隔)

**未在显式表里的** `MYOC_*` 变量走默认规则：

```typescript
// myocEnvToPath(envKey)
const path = envKey
  .replace(/^MYOC_/, '')   // 去掉前缀
  .toLowerCase()            // 全小写
  .replaceAll('_', '.');    // 下划线转点
```

**示例**：
- `MYOC_NETWORK_WS_PORT` → `network.ws.port`
- `MYOC_FEATURES_SCHEDULER` → `features.scheduler`
- `MYOC_LLM_API_KEY`（在显式表中）→ `llm.apiKey`（**不走自动规则**）

**值类型推断**（`coerceValue`）：
- `"true"` / `"false"` → boolean
- `"123"` / `"3.14"` → number
- 其他 → string（原样）

### 4.3 优先级与合并

- env 覆盖在**所有源合并后**做 → env **最高**优先级
- 数组字段（`models[]` / `cors.origins[]`）整体替换（**不拼接**）
- 中间路径不存在时**自动创建对象**（`setConfigByPath`）

```bash
# 容器化部署典型用法
export MYOC_LLM_API_KEY=sk-xxxxx
export MYOC_NETWORK_WS_PORT=18780
export MYOC_LOGGING_LEVEL=info
pnpm dev
```

## 5. 启动期校验

### 5.1 Schema 校验 (单字段)

- Zod schema 在 `json-loader.ts` 内对用户 JSON 做 `safeParse`
- 失败 → `zodToIssues()` 转 `ConfigIssue[]` → `ConfigFatalError`
- 默认模式 `strip`（未声明字段被丢弃，**不报错**）

**示例错误**：
```
❌ MyOpenClaw 配置加载失败:
  ✗ llm.apiKey: provider ≠ ollama 时 llm.apiKey 必填(非空字符串)
    路径: llm.apiKey
  ✗ network.ws.port: Number must be less than or equal to 65535
    路径: network.ws.port
```

### 5.2 跨字段校验 (validator.ts)

`validateStartupConfig(config)` 在合并完成后调用：

| 规则 | 失败路径 | 严重性 |
|------|----------|--------|
| `ws.port ≠ http.port` | `network.ws.port vs network.http.port` | fatal |
| `authToken` 不在占位符黑名单 | `security.authToken` | fatal |
| `authToken ≥ 32` (production) | `security.authToken` | fatal |
| `defaultModel ∈ models[].id` | `llm.defaultModel` | fatal |
| `provider≠ollama` → `apiKey` 非空且非 PLACEHOLDER | `llm.apiKey` | fatal |
| `provider≠local` → `embedding.apiKey` 同上 | `embedding.apiKey` | fatal |
| `proxy.enabled=true` → `url` 必填 | `llm.proxy.url` | fatal |
| `tls.enabled=true` → `cert/key` 文件存在 | `network.tls.certPath` | fatal |
| `memory.persist.backend≠none` → `path` 必填 | `memory.persist.path` | fatal |

### 5.3 致命错误 vs 警告

| 级别 | 行为 |
|------|------|
| **fatal** | 抛 `ConfigFatalError` → loader 内部打印 → `src/index.ts` 捕获后 `exit(1)` |
| **warning** | 仅 `log.warn(...)` → 启动继续 |
| **info** | 仅 `log.info(...)` → 纯提示 |

**当前没有 warning 级校验**，所有跨字段规则都是 fatal。如需软失败，在 validator.ts 中改为 `warnings` 数组 + `log.warn`。

## 6. 公开 API

`server/src/core/config/index.ts` 导出（向后兼容）：

```typescript
// 核心加载
loadConfig(): Record<string, unknown>     // 合并并缓存，返回完整 config
getConfig<T>(path: string, default?: T): T  // dot-path 读
```

## 7. 故障排查

### 7.1 常见错误

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `llm.apiKey: provider="deepseek" 时 apiKey 必填` | apiKey 是空字符串或 PLACEHOLDER | 设 `MYOC_LLM_API_KEY` 环境变量或在 JSON 填入真实 key |
| `network.ws.port vs network.http.port: WS 端口和 HTTP 端口不能相同` | 两个端口撞了 | 修改其中一个（`network.ws.port` 或 `network.http.port`） |
| `security.authToken: authToken 是占位符 "please-change-me"` | 用占位 token | 改 32 字符以上的随机字符串 |
| `memory.persist.path: memory.persist.path 必填(当 backend ≠ none)` | `backend=sqlite` 但没设 path | 加 `memory.persist.path: "~/.myopenclaw/data/memory.db"` |
| `JSON 配置文件解析失败: ...` | JSON 语法错 | 跑 `npx jsonlint <file>` 验证 |
| `JSON 配置 schema 校验失败: ...` | JSON 字段类型/必填错 | 看错误列表对照 §3 字段说明 |

## 8. 迁移与扩展

### 8.1 从旧配置迁移

旧版 `config/config.yaml` 字段：
- `gateway.host/port` → `network.ws.host/port`
- `security.apiToken` → `security.authToken`
- `storage.dataDir` → `paths.data`
- `logging.logFilePath` → `logging.file`

迁移步骤：
1. 备份旧 yaml：`cp config/config.yaml config/config.yaml.bak`
2. 用 `config/config.example.json` 作为模板改写
3. 把团队共享部分放 `config/config.yaml`，个人覆盖放 `~/.myopenclaw/config.json`
4. 跑 `pnpm dev` 验证启动日志

### 8.2 添加新配置段

1. 在 `schema.ts` 加新 schema（如 `RateLimitSegment`）
2. 顶层 `MyOpenClawConfigSchema` 加字段
3. `defaults.ts` 给新字段占位
4. `validator.ts` 加跨字段规则（如有）
5. `types.ts` 自动导出新类型
6. `config.example.json` 加示例
7. 跑 `npx vitest run tests/unit/config/`

**示例**：
```typescript
// schema.ts
export const RateLimitSegment = z.object({
  global: z.object({
    requestsPerMinute: z.number().int().min(1).default(60),
  }),
});

// 顶层
export const MyOpenClawConfigSchema = z.object({
  // ... 已有 10 段
  rateLimit: RateLimitSegment.default({ global: { requestsPerMinute: 60 } }),
});
```
