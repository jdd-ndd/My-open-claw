## 1. 文档简介

本指南旨在帮助开发者在 15 分钟内完成 MyOpenClaw 框架的安装、配置并启动第一个 AI Agent。MyOpenClaw 是一个本地优先（Local-First）、自托管的开源 AI Agent 框架，采用 TypeScript + Node.js 开发，具有以下核心特性：

- **本地优先**：所有数据存储在本地，隐私可控
- **自托管**：完全自主部署，无需依赖第三方云服务
- **多渠道接入**：支持 Telegram、Discord、飞书、WebChat 等多种渠道
- **Hub-Spoke 架构**：六层架构设计，模块化、可扩展
- **安全沙箱**：内置安全隔离机制，防止危险操作

### 架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    MyOpenClaw 系统架构                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Channels 渠道接入层                                        │
│  (Telegram / Discord / 飞书 / WebChat)                      │
│        │                                                    │
│        ▼                                                    │
│  Gateway 网关控制平面 (守护进程, 端口 18780)                │
│  (WebSocket/HTTP 服务 / 消息路由 / 状态管理 / 安全沙箱)    │
│        │                                                    │
│        ▼                                                    │
│  Agent Runtime 智能体运行时                                 │
│  (LLM 推理 / 对话管理 / 工具调用编排)                      │
│        │                                                    │
│        ▼                                                    │
│  Skill / Tools 工具执行层                                   │
│  (内置工具 / 自定义技能 / 沙箱执行)                        │

│  Memory 持久存储层                                          │
│  (SQLite / 向量数据库 / 文件系统)                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 环境准备

### 2.1 Node.js 环境安装

MyOpenClaw 要求 Node.js 20 LTS 或更高版本。以下是在不同操作系统上的安装方法。

#### Ubuntu / Debian

```bash
# 添加 NodeSource 仓库并安装 Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装版本
node --version
# 预期输出: v20.x.x

npm --version
# 预期输出: 10.x.x
```

#### macOS (使用 Homebrew)

```bash
# 安装 Node.js 20 LTS
brew install node@20

# 将 node@20 加入 PATH（如果未自动配置）
echo 'export PATH="/opt/homebrew/opt/node@20/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 验证安装版本
node --version
npm --version
```

#### Windows (使用 nvm-windows)

```powershell
# 使用 nvm-windows 安装 Node.js 20 LTS
nvm install 20
nvm use 20

# 验证安装版本
node --version
npm --version
```

#### 使用 nvm（跨平台推荐）

```bash
# 安装 nvm（Node Version Manager）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 重新加载 shell 配置
source ~/.bashrc

# 安装并使用 Node.js 20 LTS
nvm install 20
nvm use 20
nvm alias default 20

# 验证安装
node --version
npm --version
```

### 2.2 包管理器选择

MyOpenClaw 同时支持 `npm` 和 `pnpm` 作为包管理器。推荐使用 `pnpm` 以获得更快的安装速度和更小的磁盘占用。

#### 安装 pnpm

```bash
# 方式一：使用 npm 全局安装
npm install -g pnpm

# 方式二：使用 Node.js Corepack（推荐，Node.js 16.13+ 内置）
corepack enable
corepack prepare pnpm@latest --activate

# 验证安装
pnpm --version
# 预期输出: 9.x.x
```

#### 包管理器对比

| 特性 | npm | pnpm |
|------|-----|------|
| 安装速度 | 基准 | 快 2-3 倍 |
| 磁盘占用 | 基准 | 节省 50%+ |
| 幽灵依赖 | 存在 | 不存在 |
| Monorepo 支持 | Workspaces | Workspaces（更优） |
| 推荐场景 | 简单项目 | **MyOpenClaw 推荐** |

## 4. 配置文件说明

### 4.1 配置目录结构

MyOpenClaw 使用 YAML 格式的配置文件，默认配置目录结构如下：

```
~/.myopenclaw/
├── config.yaml              # 主配置文件
├── agents/                  # Agent 配置目录
│   ├── default.yaml         # 默认 Agent 配置
│   └── assistant.yaml       # 自定义 Agent 配置
├── channels/                # 渠道配置目录
│   ├── telegram.yaml        # Telegram 渠道配置
│   ├── discord.yaml         # Discord 渠道配置
│   ├── feishu.yaml          # 飞书渠道配置
│   └── webchat.yaml         # WebChat 渠道配置
├── skills/                  # 技能配置目录
│   └── web-search.yaml      # Web 搜索技能配置
├── data/                    # 数据目录
│   ├── myopenclaw.db          # SQLite 数据库
│   └── vectors/             # 向量数据
└── logs/                    # 日志目录
    ├── gateway.log          # 网关日志
    └── audit.log            # 审计日志
```

### 4.2 主配置文件 config.yaml

主配置文件是系统的核心配置，包含 Gateway 端口、存储路径、日志级别等全局设置：

```yaml
# ~/.myopenclaw/config.yaml
# MyOpenClaw 主配置文件

# Gateway 网关配置
gateway:
  # WebSocket 服务监听地址，127.0.0.1 表示仅本地访问
  # 如需远程访问，可设置为 0.0.0.0（注意安全风险）
  host: "127.0.0.1"
  # WebSocket 服务端口，默认 18780
  port: 18780
  # HTTP API 服务端口，默认 18790
  httpPort: 18790
  # WebSocket 心跳间隔（毫秒），用于检测连接存活
  heartbeatInterval: 30000
  # 连接超时时间（毫秒）
  connectionTimeout: 60000

# 安全配置
security:
  # API 访问令牌，留空表示不需要鉴权（仅本地开发使用）
  # 生产环境务必设置复杂的访问令牌
  apiToken: ""
  # 请求频率限制（每分钟最大请求数）
  rateLimit: 60
  # 命令沙箱是否启用
  sandboxEnabled: true
  # 允许执行的系统命令白名单（sandbox 模式下生效）
  allowedCommands:
    - "ls"
    - "cat"
    - "grep"
    - "find"
    - "echo"

# 存储配置
storage:
  # 数据库类型，目前支持 sqlite
  type: "sqlite"
  # 数据库文件路径
  database: "~/.myopenclaw/data/myopenclaw.db"
  # 向量数据库配置（用于语义记忆）
  vectorStore:
    type: "local"
    path: "~/.myopenclaw/data/vectors"
    # 嵌入模型维度
    dimension: 1536

# 日志配置
logging:
  # 日志级别：debug / info / warn / error
  level: "info"
  # 日志文件路径
  file: "~/.myopenclaw/logs/gateway.log"
  # 审计日志路径
  auditFile: "~/.myopenclaw/logs/audit.log"
  # 日志文件最大大小（MB），超过后自动轮转
  maxSize: 50
  # 保留的日志文件数量
  maxFiles: 7

# LLM 提供商默认配置
llm:
  # 默认使用的 LLM 提供商
  defaultProvider: "openai"
  # 请求超时时间（毫秒）
  timeout: 120000
  # 最大重试次数
  maxRetries: 3

# WebUI 配置
webui:
  # 是否启用 WebUI
  enabled: true
  # WebUI 端口
  port: 18791
  # 是否允许远程访问
  remoteAccess: false
```

### 4.3 Agent 配置文件

每个 Agent 对应一个 YAML 配置文件，存放在 `~/.myopenclaw/agents/` 目录下：

```yaml
# ~/.myopenclaw/agents/default.yaml
# 默认 Agent 配置

# Agent 唯一标识符
id: "default"
# Agent 显示名称
name: "MyOpenClaw 助手"
# Agent 描述
description: "默认的通用助手 Agent"

# LLM 模型配置
model:
  # 使用的 LLM 提供商
  provider: "openai"
  # 模型名称
  model: "gpt-4o"
  # 温度参数（0-2，越高越随机）
  temperature: 0.7
  # 最大输出 Token 数
  maxTokens: 4096
  # 系统 Prompt
  systemPrompt: |
    你是 MyOpenClaw 助手，一个功能强大的 AI Agent。
    你可以帮助用户回答问题、执行任务、管理日程等。
    请用简洁清晰的中文回答用户的问题。

# 记忆配置
memory:
  # 是否启用对话记忆
  enabled: true
  # 短期记忆窗口大小（保留最近 N 轮对话）
  shortTermWindow: 20
  # 是否启用长期语义记忆
  longTermEnabled: true
  # 长期记忆检索数量
  retrievalCount: 5

# 工具配置
tools:
  # 启用的内置工具列表
  enabled:
    - "web_search"       # 网页搜索
    - "file_read"        # 文件读取
    - "file_write"       # 文件写入
    - "shell_exec"       # 命令执行（受沙箱保护）
    - "http_request"     # HTTP 请求
  # 工具执行超时时间（毫秒）
  timeout: 30000

# 渠道绑定（指定该 Agent 响应哪些渠道的消息）
channels:
  - channelId: "telegram"
    # 路由规则：匹配特定用户
    userIds: ["*"]  # "*" 表示匹配所有用户
  - channelId: "webchat"
    userIds: ["*"]
```

## 5. LLM API Key 配置

MyOpenClaw 需要配置 LLM 提供商的 API Key 才能让 Agent 进行智能推理。支持多种配置方式。

### 5.1 环境变量方式

这是最推荐的方式，API Key 不会写入配置文件，避免泄露风险。

```bash
# 创建环境变量文件
cat << 'EOF' > ~/.myopenclaw/.env

# ===== MyOpenClaw 环境变量配置 =====

# OpenAI API Key
# 获取地址: https://platform.openai.com/api-keys
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Anthropic Claude API Key
# 获取地址: https://console.anthropic.com/
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 通义千问 API Key（阿里云百炼平台）
# 获取地址: https://dashscope.console.aliyun.com/
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# DeepSeek API Key
# 获取地址: https://platform.deepseek.com/
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 智谱 GLM API Key
# 获取地址: https://open.bigmodel.cn/
ZHIPU_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

EOF

# 设置文件权限，仅当前用户可读写
chmod 600 ~/.myopenclaw/.env

# 加载环境变量（可选，MyOpenClaw 启动时会自动加载 .env 文件）
export $(cat ~/.myopenclaw/.env | xargs)
```

### 5.2 配置文件方式

也可以在主配置文件中直接配置 API Key（不推荐用于生产环境）：

```yaml
# ~/.myopenclaw/config.yaml（追加 LLM 密钥配置）

llm:
  providers:
    # OpenAI 配置
    openai:
      apiKey: "sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      baseURL: "https://api.openai.com/v1"
    
    # Anthropic Claude 配置
    anthropic:
      apiKey: "sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      baseURL: "https://api.anthropic.com"
    
    # 通义千问配置（阿里云）
    dashscope:
      apiKey: "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      baseURL: "https://dashscope.aliyuncs.com/compatible-mode/v1"
    
    # DeepSeek 配置
```

### 5.3 密钥安全最佳实践

| 实践 | 说明 | 推荐程度 |
|------|------|----------|
| 使用 `.env` 文件 | 密钥与代码分离，不纳入版本控制 | 强烈推荐 |
| 设置文件权限 `600` | 仅文件所有者可读写 | 强烈推荐 |
| 使用系统密钥管理 | macOS Keychain / Linux Secret Service | 生产推荐 |
| 环境变量注入 | 通过 CI/CD 或容器编排注入 | 生产推荐 |
| 写入 config.yaml | 密钥存在于配置文件中 | 不推荐 |
| 硬编码在代码中 | 密钥直接写在源码中 | 禁止使用 |

```bash
# 确保 .env 文件不会被 Git 追踪
echo ".env" >> ~/.myopenclaw/.gitignore
echo "*.key" >> ~/.myopenclaw/.gitignore
echo "*secrets*" >> ~/.myopenclaw/.gitignore
```

#### 方式二：编写 TypeScript 脚本创建

对于更复杂的自动化场景，可以通过编程方式创建任务：

```typescript
// create-task.ts
// 自动化任务创建脚本 - 演示如何通过编程方式创建定时任务

// 导入 MyOpenClaw SDK 客户端
import { MyOpenClawClient } from '@myopenclaw/sdk';

/**
 * 创建每日科技新闻摘要任务的示例脚本
 * 该脚本演示了如何通过 MyOpenClaw SDK 编程式地创建定时任务
 */
async function main(): Promise<void> {
  // 创建 MyOpenClaw 客户端实例
  // 默认连接本地 ws://127.0.0.1:18780
  const client = new MyOpenClawClient({
    gatewayUrl: 'ws://127.0.0.1:18780',
    // 如有配置 API Token，需要传入
    apiToken: process.env.OPENCLAW_API_TOKEN,
  });

  try {
    // 连接到 Gateway
    await client.connect();
    console.log('已连接到 MyOpenClaw Gateway');

    // 创建定时任务
    const task = await client.task.create({
      // 任务名称
      name: '每日科技新闻摘要',
      // Cron 表达式：每天 09:00 执行
      cron: '0 9 * * *',
      // 目标 Agent ID
      agentId: 'default',
      // 任务触发时发送给 Agent 的消息
      message: '请搜索今天的科技新闻，挑选最重要的5条，生成一份简洁的新闻摘要。',
      // 结果推送的目标渠道
      channelId: 'webchat',
      // 结果推送的目标用户 ID
      userId: 'user_001',
      // 任务是否启用
      enabled: true,
      // 任务元数据（可选）
      metadata: {
        category: 'news',
        priority: 'normal',
      },
    });

    console.log('定时任务创建成功:');
    console.log(`  任务 ID: ${task.id}`);
    console.log(`  任务名称: ${task.name}`);
    console.log(`  Cron 表达式: ${task.cron}`);
    console.log(`  下次执行: ${task.nextRunAt}`);

    // 查询所有任务
    const tasks = await client.task.list();
    console.log(`\n当前共有 ${tasks.length} 个定时任务:`);
    for (const t of tasks) {
      console.log(`  - [${t.id}] ${t.name} | ${t.cron} | ${t.enabled ? '已启用' : '已禁用'}`);
    }
  } catch (error) {
    console.error('操作失败:', error);
    process.exit(1);
  } finally {
    // 断开连接
    await client.disconnect();
    console.log('\n已断开与 Gateway 的连接');
  }
}

// 执行主函数
main();
```

运行脚本：

```bash

npx tsx create-task.ts
```

## 10. 常见问题

### Q1: 启动时报端口被占用怎么办？

```bash
# 查看端口占用情况
lsof -i :18780

# 如果是之前未正常关闭的 MyOpenClaw 进程，可以强制结束
kill -9 <PID>

# 或者修改配置文件使用其他端口
# 编辑 ~/.myopenclaw/config.yaml
# gateway:
#   port: 18790  # 修改为其他可用端口
```

### Q2: LLM API 调用超时怎么办？

```yaml
# 在 config.yaml 中调整超时和重试配置
llm:
  timeout: 180000    # 增加超时时间到 3 分钟
  maxRetries: 5      # 增加重试次数
```

### Q3: 如何查看详细的调试日志？

```bash
# 启动时设置日志级别为 debug
pnpm myopenclaw start --log-level debug

# 或在配置文件中修改
# logging:
#   level: "debug"
```

### Q4: 如何完全重置系统？

```bash
# 停止 Gateway
pnpm myopenclaw stop

# 备份后删除配置目录
mv ~/.myopenclaw ~/.myopenclaw.backup.$(date +%Y%m%d)

# 重新初始化
pnpm myopenclaw init
```

### Q5: 如何更新到最新版本？

```bash
# 拉取最新代码
cd ~/myopenclaw
git pull origin main

# 安装依赖
pnpm install

# 重新构建
pnpm build

# 重启 Gateway
pnpm myopenclaw restart
```
