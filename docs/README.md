## 文档导读

MyOpenClaw 是一个本地优先、自托管的开源 AI Agent 框架，基于 TypeScript + Node.js 开发。本套文档体系完整覆盖了从架构设计到客户端开发的全生命周期技术资料，面向开发者、测试人员和最终用户三类角色。

文档按照**总览 → 架构 → 模块详解 → 接口规范 → 操作指南 → 团队协作**的逻辑组织，建议首次阅读按顺序进行，日常使用按需检索。

## 文档规范

### 文件命名规范

- 采用 `序号-文档名称.md` 格式，序号用两位数字（00-19）
- 序号决定文档的推荐阅读顺序
- 文档名称使用中文，简洁明了反映文档内容

### 格式规范

- 统一使用 Markdown 格式编写
- 标题层级：一级标题（`#`）用于文档标题，二级标题（`##`）用于主要章节
- 代码块标注语言类型（typescript、bash、json 等）
- 表格用于结构化对比信息
- Mermaid 图表用于流程和架构可视化

### 版本管理规范

- 每个文档头部包含版本号、修订日期、修订人信息
- 版本号采用语义化版本（Semantic Versioning）：`主版本.次版本.修订号`
- 文档变更统一记录至 `16-变更记录.md`

### 术语一致性

- 所有专有术语以 `13-术语表.md` 为准
- 首次出现术语时给出全称，后续使用缩写
- 跨文档引用时标注来源文档编号
